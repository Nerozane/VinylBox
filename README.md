# VinylBox

Vinyl collection catalog — Website Development 2 assignment.

## Pages

- **Welcome** (`index.html`) — greeting, featured carousel, link to catalog
- **Catalog** (`catalog.html`) — CRUD, search, sort, Handlebars, Swiper
- **About** (`about.html`) — project info, guestbook, FAQ

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server.

## Stack

HTML, CSS, JavaScript, [Handlebars](https://handlebarsjs.com/), [Swiper](https://swiperjs.com/), `localStorage`.
